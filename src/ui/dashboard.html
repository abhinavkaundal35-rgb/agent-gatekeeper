How External Client AI Agents Call Gatekeeper

External AI Agents (written in Python, Node.js, LangChain, or cURL) call the Gatekeeper Interceptor API:

1. Python (Requests / HTTPX)

import requests

url = "http://127.0.0.1:8000/api/v1/gatekeeper/evaluate"
payload = {
    "agent_id": "agent-amz-001",
    "api_token": "amz_gatekeeper_token_...",
    "customer_id": "cust-amz-001",
    "action_type": "PURCHASE_ORDER",
    "payload": {
        "items": [{"item_id": "AMZ-ELEC-01", "name": "Echo Dot", "category": "Electronics", "unit_price_inr": 4499.0, "quantity": 1}],
        "shipping_address": {"address_line": "MG Road", "city": "Bengaluru", "state": "Karnataka", "pincode": "560001"}
    }
}

response = requests.post(url, json=payload).json()
print("Decision:", response["decision"]) # Returns 'ALLOW', 'ASK CUSTOMER', or 'BLOCK'

2. cURL

curl -X POST "http://127.0.0.1:8000/api/v1/gatekeeper/evaluate" \
     -H "Content-Type: application/json" \
     -d '{
       "agent_id": "agent-amz-001",
       "action_type": "PURCHASE_ORDER",
       "customer_id": "cust-amz-001",
       "payload": {"items": [{"item_id": "AMZ-GROC-01", "name": "Tata Tea", "category": "Grocery", "unit_price_inr": 520.0, "quantity": 1}], "shipping_address": {"pincode": "560001", "city": "Bengaluru", "state": "Karnataka", "address_line": "MG Road"}}
     }'
