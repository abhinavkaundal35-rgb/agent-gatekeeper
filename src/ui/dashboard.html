Academic Requirement: Distinct AI Agents for Specific Work:
To uphold the Principle of Least Privilege, each customer AI agent is assigned a dedicated responsibility with unique cryptographic tokens and scoped permissions:
  • ALLOW Agent (agent-allow-001): Routine shopping under ₹2,000 threshold (Auto-Approved).
  • ASK CUSTOMER Agent (agent-ask-002): High-value shopping over ₹2,000 (Requires Customer Challenge Approval).
  • HISTORY CHECK Agent (agent-history-003): Read-only past orders auditor (Scope: orders:view). Buying attempts are BLOCKED!
  • BLOCK Agent (agent-block-004): Revoked/decommissioned bot. Any request is immediately BLOCKED by Rule SEC-R01.
  • RETURNS Agent (agent-return-005): Dedicated return filing specialist (Scopes: returns:create, returns:view, orders:view).

How External Client AI Agents Call Gatekeeper

External AI Agents (written in Python, Node.js, LangChain, or cURL) call the Gatekeeper Interceptor API:

1. Python (Requests / HTTPX)

import requests

url = "http://127.0.0.1:8000/api/v1/gatekeeper/evaluate"
payload = {
    "agent_id": "agent-amz-001",
    "api_token": "amz_gatekeeper_token_...",
    "customer_id": "cust-amz-001",
    "action_type": "PURCHASE_ORDER",
    "payload": {
        "items": [{"item_id": "AMZ-ELEC-01", "name": "Echo Dot", "category": "Electronics", "unit_price_inr": 4499.0, "quantity": 1}],
        "shipping_address": {"address_line": "MG Road", "city": "Bengaluru", "state": "Karnataka", "pincode": "560001"}
    }
}

response = requests.post(url, json=payload).json()
print("Decision:", response["decision"]) # Returns 'ALLOW', 'ASK CUSTOMER', or 'BLOCK'
